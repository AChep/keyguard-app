Keyguard Autofill
Local, encrypted credential filling
Options Debug

This extension autofills logins from your Keyguard desktop vault directly into websites — locally, with no cloud involved. A small native agent bridges the extension and the app using either Native Messaging (Firefox / Chrome / Edge) or an encrypted WebSocket loopback channel (Safari / manual WebSocket mode).

End-to-end encrypted
Keys are negotiated with X25519 (ECDH); every message is sealed with AES-256-GCM. The WebSocket channel answers an HMAC challenge before any secret is released.
Local only
Nothing leaves your machine. The agent rejects any non-loopback connection and the vault stays on your device.
One shortcut
Press Ctrl+Shift+Space on a login page to fill the single match, or open the picker when there are several.

Get started

1
Open Keyguard, go to Settings → Autofill and enable Browser autofill agent.
2
Make sure your vault is unlocked.
3
On a login page, click the extension icon, press Ctrl+Shift+Space, or use the popup buttons to copy username, password or TOTP.

Testing the WebSocket flow

The WebSocket / Safari flow can be tested from any browser (for example Firefox) by forcing it in the extension options:

1
In Keyguard, copy the pairing code shown under the agent toggle.
2
In the extension options, set Connection mode → WebSocket, then Pair with the code and a PIN or master password.
3
Use Test query to confirm the encrypted handshake and HMAC exchange succeed.
