## Theme and color

### Theme

**Follow system settings** switches with your system's light and dark mode.
The other options are **Light** and **Dark**.

### Use contrast black theme

Uses pure black backgrounds while a dark theme is active.

### Use expressive theme

Uses the expressive layout, with wider padding around content.

### Tint color

Sets the accent color across the app. **Follow system settings** uses the
system's accent or wallpaper color, where the system has one. The other options
are built-in colors, such as Red, Blue, Teal and Amber.

## Text and motion

### Font

**Follow system settings**, **Roboto**, **Noto** or **Atkinson Hyperlegible**.
Atkinson Hyperlegible is a typeface designed for readers with low vision.

### Rich text formatting

Renders Markdown in notes instead of the raw text.

### Transition animation

Sets the animation between screens: **Disabled**, **Crossfade** or
**Dynamic**.

## Navigation

### Navigation items

Sets the order and visibility of navigation items. You can add custom filters
as items.

### Show labels on navigation buttons

Shows a text label on each navigation button.

## Icons

### Load App icons

Shows app icons for items with an Android app URI. For an app that isn't
installed, the icon downloads from Google Play if **Load Website icons** is on.

### Load Website icons

Downloads the icon of each item's website.

### Load Gravatar icons

Shows a Gravatar avatar for items with an email address.

:::caution
Website icons download over the network, which can reveal the websites in
your vault to your internet provider. App icons download from Google Play, and
Gravatar avatars send a hash of each email address to Gravatar.
:::

## Behavior

### Open links in external browser

Opens links in your default browser app instead of an in-app browser. Android
only.

### Keep the screen on while viewing items

Keeps the screen on while an item is open. Android only.

### Minimize on copy

Minimizes the window after you copy a value. Linux, macOS and Windows only.

### Close to system tray

Closing the window keeps Keyguard running in the system tray, if the desktop
has one. Linux, macOS and Windows only.

## Layout

Keyguard can show the list and the open item side by side. Each setting applies
only when the window is wide enough for two panels, so it mostly affects
tablets and desktop windows.

### Allow two panel layout in portrait mode

Allows two panels in portrait orientation.

### Allow two panel layout in landscape mode

Allows two panels in landscape orientation.
