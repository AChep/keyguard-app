To suggest a feature or discuss Keyguard, pick the channel that fits your
feedback.

| To | Use |
| --- | --- |
| Request a feature | A GitHub issue with the **Feature request** template |
| Report a bug | A GitHub issue with the **Bug report** template, plus [Record logs](#record-logs) if it helps |
| Share an idea, ask a question or start a poll | [GitHub Discussions](https://github.com/AChep/keyguard-app/discussions) |
| Talk with other users | The [r/keyguard](https://www.reddit.com/r/keyguard/) community on Reddit |
| Write to the developer privately | **Contact us** in the app |
| Report a security vulnerability | Email, as in [Report a vulnerability](/docs/report-vulnerability/) |

## Suggest a feature

1. Search the [issues](https://github.com/AChep/keyguard-app/issues) and
   [Ideas](https://github.com/AChep/keyguard-app/discussions/categories/ideas)
   for the same request. If you find it, react to it or add a comment instead.
2. Open a [new issue](https://github.com/AChep/keyguard-app/issues/new/choose)
   and select the **Feature request** template.
3. Describe the problem and the solution you want, then submit the issue.

To talk an idea through before it's a concrete request, post it in **Ideas**
instead.

## Start a discussion

GitHub Discussions has a category for each kind of post.

| Category | For |
| --- | --- |
| **Ideas** | Ideas for new features |
| **Q&A** | Questions. The reply that answers one gets marked as the answer. |
| **Polls** | Votes on a question |
| **General** | Anything else |
| **Show and tell** | Things you made with Keyguard |

1. Open [GitHub Discussions](https://github.com/AChep/keyguard-app/discussions)
   and select **New discussion**.
2. Select a category.
3. Enter a title and your post, then select **Start discussion**.

The maintainer posts updates in **Announcements**.

## Send a message from the app

**Contact us** sends a private message by email. It isn't in the Wear OS app.

1. In Keyguard, open **Settings > Other > Contact us**.
2. In **Your message**, enter your feedback in English.
3. Select **Send**. Your email app opens with the message.
4. Send the email.

## Record logs

Logs show what the app did before a bug. Keyguard keeps them in memory only,
and only while recording is on. The Wear OS app has no logs.

1. Open **Settings > Other > Logs** and select **Start recording**.
2. Repeat the steps that cause the bug.
3. Select **Export**. Keyguard saves a ZIP file to your Downloads folder.
4. Review the file, then attach it to your bug report.

**Stop recording** deletes the recorded logs.
