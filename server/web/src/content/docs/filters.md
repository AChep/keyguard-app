Filters narrow the vault list to the items that match. A custom filter saves a
set of filters under a name, so you can apply it with one selection.

## Save a custom filter

1. Set the filters.
2. Select the save icon.
3. Enter a **Name** and confirm.

To apply a custom filter, select it in the side panel or above the vault list.
Select it again to reset the filters. Keyguard starts with custom filters for
**Login**, **Card**, **Identity**, **Note** and **One-time password**.

Custom filters stay on this device and don't sync.

## Manage custom filters

Open the vault's menu and select **Custom filters**. Select a filter to see
its conditions, rename it or delete it. You can't change a saved filter's
conditions: save a new one instead.

To show a custom filter in the navigation bar, see
[Navigation items](/docs/appearance/#navigation-items).

On Android, each custom filter is a shortcut that can be added to the home screen:

1. Open the vault's menu and select **Custom filters**.
2. Select the filter, then **Add to Home screen**.

## Filter sections

| Section | Matches |
| --- | --- |
| **Custom** | Your custom filters |
| **Account** | Items of an account |
| **Organization** | Items of a Bitwarden organization. **My vault** matches items outside any organization. |
| **Type** | Items of a type, such as **Login** |
| **Tag** | Items with a tag. **No tag** matches untagged items. |
| **Folder** | Items in a folder. **No folder** matches items outside any folder. |
| **Collection** | Items in a collection. **No collection** matches items outside any collection. |
| **Miscellaneous** | **One-time password**, **Attachments**, **Passkeys**, **Auth re-prompt**, **Pending** for unsynced changes, **Failed** for failed syncs, and **Ignored alerts** |
