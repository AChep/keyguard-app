## Global shortcuts

Global shortcuts work in any app while Keyguard is running. On Linux, they need an X11 session.

| Linux and Windows | macOS | Action |
| :---------------- | :---- | :----- |
| Ctrl+Shift+Space | Cmd+Shift+Space | Open Quick search |
| Ctrl+Shift+L | Cmd+Shift+L | Lock the vault |

### Quick search

| Linux and Windows | macOS | Action |
| :---------------- | :---- | :----- |
| Up or Down | Up or Down | Select the previous or next result |
| Tab or Shift+Tab | Tab or Shift+Tab | Select the next or previous action |
| Enter | Enter | Run the selected action, or the first copy action. Quick search stays open. |
| Esc | Esc | Clear the search field, or close Quick search |
| Ctrl+Alt+F | Cmd+Option+F | Clear and focus the search field |
| Ctrl+C | Cmd+C | Copy the username or other main field |
| Ctrl+Shift+C | Cmd+Shift+C | Copy the password, card security code or private key |
| Ctrl+Alt+C | Cmd+Option+C | Copy the one-time password |
| Ctrl+Shift+F | Cmd+Shift+F | Open the website |

Auto-type types into the app you used before opening Quick search. See
[Auto-type a login](/docs/quick-search/#auto-type-a-login).

| Windows | macOS | Action |
| :------ | :---- | :----- |
| Ctrl+T | Cmd+T | Type the username, Tab, then the password |
| Ctrl+Shift+T | Cmd+Shift+T | Choose what to type: 1 for the username, 2 for the password, 3 for the one-time password |

## Local shortcuts

### App-wide shortcuts

| Linux and Windows | macOS | Action |
| :---------------- | :---- | :----- |
| Esc | Esc | Close a popup, clear the search field, or go back |
| Ctrl+Alt+F | Cmd+Option+F | Clear and focus the search field |
| Ctrl+N | Cmd+N | Create an item in the vault list, or a send in the send list |

## Item view

| Linux and Windows | macOS | Action |
| :---------------- | :---- | :----- |
| Ctrl+C | Cmd+C | Copy the username or other main field |
| Ctrl+Shift+C | Cmd+Shift+C | Copy the password, card security code or private key |
| Ctrl+Alt+C | Cmd+Option+C | Copy the one-time password |
| Ctrl+Shift+F | Cmd+Shift+F | Open the first URI, or its URL override |
| Ctrl+R | Cmd+R | Reveal or conceal hidden fields |
| Ctrl+E | Cmd+E | Edit the item |
| Delete | Delete | Move the item to the trash, or delete it |
| Ctrl+Delete | Cmd+Delete | Delete the item |

## Send view

| Linux and Windows | macOS | Action |
| :---------------- | :---- | :----- |
| Ctrl+C | Cmd+C | Copy the public URL |
| Ctrl+Shift+F | Cmd+Shift+F | Open the public URL |
| Delete | Delete | Delete the send |
| Ctrl+Delete | Cmd+Delete | Delete the send |

## Generator

| Linux and Windows | macOS | Action |
| :---------------- | :---- | :----- |
| Ctrl+C | Cmd+C | Copy the value, or a generated key's fingerprint |
| Ctrl+R | Cmd+R | Generate a new value |
