Attach files to any vault item. A recovery code image, a scanned document, or a key file stays with the login or note it belongs to.

Downloads run in the background, so you can keep working while a file transfers.

You can also open an attachment in-app. It renders inside Keyguard instead of being written to your device first, which keeps sensitive files off local storage where other apps or backups might pick them up.

<Screenshot src={previewImage} caption="Previewing an image attachment in-app, without writing it to disk first" />

Images aren't the only thing that opens in-app. Text and Markdown files render inline as well, in raw and formatted views with basic syntax highlighting, so a recovery note or a config file stays off the filesystem too.
