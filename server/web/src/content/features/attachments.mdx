Attach files to any vault item. A recovery code image, a scanned document or a
key file stays with the login or note it belongs to.

<Screenshot src={previewImage} caption="Previewing an image attachment in-app, without writing it to disk first" />

Images, text, Markdown and ZIP archives open inside Keyguard without being
saved to disk, so sensitive files stay out of reach of other apps and
backups.
