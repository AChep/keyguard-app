Keyguard can maintain a backup repository of your vault, taking a fresh copy as your data changes. Unlike a one-off export, it runs in the background and stays current. Backups are incremental and encrypted with a password.

An accidental deletion or a bad sync then costs you nothing. An earlier snapshot still has the item.

<Screenshot src={backupRepository} caption="The backup screen, with a snapshot in progress, repository metadata, and snapshot retention." />

The [backups documentation](/docs/backups/) covers repositories, scheduling, and restoring. For a one-time copy instead, see [data export](/features/data-export/).
