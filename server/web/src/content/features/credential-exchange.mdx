On Android, Keyguard implements the FIDO Alliance's Credential Exchange Format, so logins, passkeys, one-time passwords, cards, identities, notes, SSH keys and folders can move straight between Keyguard and another password manager on the same device.

See the [credential exchange documentation](/docs/credential-exchange/) for the requirements and what transfers and what does not. If you are looking for exporting into a local file, see [data export](/features/data-export/).
