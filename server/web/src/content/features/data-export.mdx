Take a copy of your vault whenever you need it, from a single item to an
organization's items. The export is a password-protected archive, and it can
carry the attached files too.

<Screenshot src={exportAccount} caption="An account's export options, for individual items or the entire vault." />

Move to another tool, archive a copy for safekeeping, or hand off an
organization's data when ownership changes.
