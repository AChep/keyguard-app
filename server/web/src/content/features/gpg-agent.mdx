Keyguard can act as a GPG agent, so `gpg` and `git` sign and decrypt with the
keys in your vault. Apps that support OpenKeychain can use Keyguard as their
OpenPGP provider.

The private key stays in Keyguard. You see which app wants which key, and you
decide whether it can use it.
