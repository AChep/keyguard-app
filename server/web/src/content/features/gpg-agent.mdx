Keyguard can act as a GPG agent — when a tool needs a signature or a decryption, the agent answers with the matching key while the private material stays in one managed place.

This works on desktop (Linux, macOS and Windows). When a request comes in, an approval dialog shows you which application wants to use which key, and you decide how long that approval lasts.
The generator can create new Ed25519 or RSA key pairs, and public keys can be fetched from a keyserver. When you're ready to wire it up, the [setup guide](/docs/gpg-agent/) covers it.
