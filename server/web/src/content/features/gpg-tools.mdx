Keyguard bundles a set of OpenPGP tools that work straight from your vault. Sign a message, verify a signature, encrypt to a recipient, or decrypt something you received without exporting private material or dropping to a command line.

For the item type behind them — supported algorithms, identifiers, and how keys are stored — see [GPG keys](/docs/gpg-keys/), and to serve those keys to a local `gpg`, the [GPG agent](/docs/gpg-agent/).
