Keyguard has OpenPGP tools built-in. Sign a message, verify a signature, encrypt to a recipient, or decrypt something you received, without exporting private material or dropping to a command line.

For the item type behind them, including supported algorithms, identifiers, and how keys are stored, see [GPG keys](/docs/gpg-keys/). To serve those keys to a local `gpg`, see the [GPG agent](/docs/gpg-agent/).
