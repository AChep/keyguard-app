Search matches titles and fields as you type, so a username, an email address
or part of a website finds the right item. Filters by item type, folder and tag
cut a broad list down without leaving the search field.

<Screenshot src={searchFields} caption="A partial query surfaces matches instantly, highlighted across titles, fields, and attachments." />

Qualifiers narrow a search to one field. `attachment:` finds items by the
names of their files, and stacks with the type and tag filters.

<Screenshot src={searchAttachment} caption="The attachment: qualifier narrows results to items with a matching file, alongside the type and tag filters." />
