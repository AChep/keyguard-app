Keyboard shortcuts put Keyguard's common actions under your fingers, from
opening Quick search to copying a password or a one-time code.

Placeholders turn an item's links into templates that fill in the item's own
data when you open them. URL overrides add a button that rewrites a matching
link, or launches a local program.
